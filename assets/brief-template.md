# Talk Brief | 技术分享简报

- **Working title / 题目**: ...
- **Purpose / 分享后听众能做什么**: 讲完能复述/推导/排查哪一个完整问题？
- **Audience / 听众已知与未知**: 已知...；未知...；不要默认掌握...
- **Format / 载体**: 飞书 / Markdown / Slides / PDF / Web；有无交互和离线要求？
- **Timing / 时间**: 共...min；主讲...；讨论...；互动和切屏已计入？
- **Driving question / 一条主线**: ...
- **Tracked object / 一直跟踪的对象**: 一条请求/一个轨迹/一张张量/一次实验...
- **Anchor examples / 固定案例**: 直觉 A... → 桥接 B... → 工程 C...
- **Example invariant / 不能悄悄改变的条件**: 输入、状态、符号、单位、奖励/数值、版本...
- **Core derivation / 唯一重点推导**: 哪个推导真正必要？预计时长及退出条件...
- **Legacy knowledge bridge / 已有知识的连接**: 相同...；不同...；类比的限制...
- **Can skip / 可压缩与可跳过**: ...
- **Known sources / 已核验资料**: ...
- **Author hypotheses / 尚未验证**: ...
- **Release level / 公开范围**: public / private / sensitive (需授权)
- **Accessibility / 展示要求**: 字号、图的静态备用、公式渲染、离线备用...

## Narrative in six sentences / 六句话说清主线

1. 听众已经理解 ____。
2. 但是遇到 ____，旧框架解释不了 ____。
3. 我们跟着 ____ 观察每一步会发生什么。
4. 新机制 ____ 解答了 ____，最小实例为 ____。
5. 它落到工程后，又遇到 ____，需要 ____ 这样的系统能力。
6. 最终听众应当能独立回答 ____，并知道 ____ 仍待验证。
