# Changelog

## 0.3.0 — 2026-11-17

- Learned from the public LazyAttention teaching structure: follow one output, add constraints progressively, compare implementations on controlled inputs, separate logical demos from measured execution, and finish with evidence.
- Added an input contract (topic-only test mode, assumed audience and 30/5-minute duration, recommended fields, JSON Schema and standard-library validator).
- Added demo storyboard specification and validation, including prediction, one-variable change, step-by-step reveal, causal explanation, limits and a static fallback.
- Added cross-domain B+ tree smoke-test fixture with a manual acceptance rubric to detect overfitting to RL/CUDA examples.
- Updated bilingual README, templates and CI for the new validation checks.

## 0.2.0 — 2026-11-11

- Added evidence-aware source review: separate notes, visible artifacts, observed timing, and post-talk feedback.
- Strengthened stable-example mapping, deep-dive time budgets, and safe-shortening paths.
- Added content-level anchor validation and an optional visual/fallback manifest audit.
- Added warnings for explicitly marked speaking passages that exceed plausible time budgets.
- Added final-export inspection rules for pagination, math, image placement, and projection readability.
- Added a conservative pre-publication secret scanner and CI validation.
- Added a bilingual README, reusable example, and publication instructions.

## 0.1.0 — 2026-11-11

- Initial question-driven, dual-track presentation workflow and structural alignment validator.
